## 🧰 How to Use This Notebook

1. **Open the notebook in Google Colab**  
   - Go to [https://colab.research.google.com](https://colab.research.google.com)
   - Click on **"GitHub"** and paste the link to the `.ipynb` file (if provided via GitHub)  
   *OR*  
   - Click on **"Upload"** and upload the `.ipynb` file you downloaded

2. **Make a copy in your Google Drive**  
   File → Save a Copy in Drive

3. **Follow along the notebook sections**  
   Read each code block, run it, and complete the exercises and quizzes.

4. **Mount your Google Drive** (in section 0.7)  
   This will let you access files saved in your Drive.
